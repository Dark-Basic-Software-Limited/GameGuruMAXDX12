**DX11 vs DX12 (the numbers that decide it):** DX11 (GGGrass.cpp instanced) drew a FIXED 400,000 one-quad instances over an 8x8 camera grid of cell side (lod_dist+2500)/3, so near density = 56250/(lod_dist+2500)^2 per sq inch (87.19M/(L+2500)^2 per m2) - the Grass Draw Distance WAS the density control. DX12 (Wicked hair, one system per 5280-unit chunk) laid a constant 100,000 strands per chunk = 5.56/m2. Equal only at lod ~1460; biome levels (lod 4208-7000) were 2.9-5.8x DX11. The terrain tool's "Grass Density" is paint_density = brush coverage (level data), NOT a render density - neither engine had one.

**3.116 (Lee asked 2026-10-15, Lee-confirmed 2026-10-16, notes §3.116, checklist 246):** GrassStrandsForTier in GGTerrainWicked.cpp = DX11 formula x Grass Density % (setup.ini grassdensity x level visuals.GrassDensity, they MULTIPLY) x tier weight (1/0.18/0.05) x low-VRAM 0.75, clamped 1024..150000; low-VRAM ceiling 100k applied AFTER the percentage. Default DX11 mode ON (grassdensitydx11=0 = old constant). Measured: exact counts at 5 draw distances; DX12TESTLEVEL +38% FPS, -400 MB.

**Live rebuild pattern (reuse it for any per-chunk grass parameter):** latch the inputs after 15 still frames (immediately when no grass exists - level load grows right first time), record builtStrands per chunk, and let the phase-1 pass re-queue stale chunks through the existing tier-change fullReset path (nearest first, 6/pass, old grass renders until replaced). Do NOT use ForceGrassRebuild for live changes - it clears the chunk map and every chunk re-waits the 30-frame settle gate (the field blanks). Staleness must be checked whenever the chunk has grass, not only at an unchanged tier (a paint stroke erases the tier record).

**3.117 far field (Lee asked 2026-10-16, Lee-confirmed 2026-10-16, engine 2cc2de0a / game 0a447fed, notes §3.117, checklist 247):** engine `HAIR_FLAG_GG_DX11_FALLOFF` (global `wi::gg_grass_dx11_falloff`, game `gg_grass_far_mode` 1 default / 0 old strand LOD / 2 baseline; setup.ini grassfardx11, harness SET_GRASSFARMODE): every strand full size to L, then drops at L + u*2500, u = Irwin-Hall(3) from the strand hash = DX11's noise dissolve (GGGrassPS `dist > noise*2500 + L`); VS 80-100% fade off; every chunk within R + half-diagonal at full density (no 18%/5% rings); flowers full distance. Measured survival within 0.03 of the DX11 model per band; +0.24 ms / ~+60 MB vs mode 0 on DX12TESTLEVEL (365k vs 180k strands). REVIEW FIND (predates 3.117, since the port): strands >= 65536 in a system were bit-identical COPIES (RNG seed packing, [[project-rules-rendering-dx12]]) - any chunk over 65,536 strands drew ~65.5k unique blades (3.116 at the 1500 default: a third were copies); fixed in the engine 3.117, +20-35% coverage at draw distance 1500, levels at 2392+ unchanged. With grassdensitydx11=0 the far ring stays tiered (constant density would grow with R^2). Probe: tools/harness/grass_falloff_probe.sh (needs the rebuild-aware settle + 20 s relax and the full-window NDC mapping - [[project-measuring-rules]]).

**3.118 no grass on sand/rock (Lee asked 2026-10-16, notes §3.118, checklist 248):** DX11 resolves Auto grass (byte 1) on a material with no matching grass (grassMaterialTypes 255) to EMPTY; DX12's GGGrass_ScanRegion (Stage B.10) and the Match-on brush spray (B.9) wrote real type 0 + 2 = Course Grass, and the hair CS draws an unresolved 1 as Course Grass too - so bare must be written 0. Fixed both + a GetNormal guard (GetMaterialIndex falls back to bare material 31 on a failed normal). Levels saved by DX12 since 07-10 keep the byte (indistinguishable from deliberate Match-off Course Grass) - opt-in repair GRASS_CLEAR_BARE, audit GET_GRASSMAP_AUDIT, probe tools/harness/grass_bare_probe.sh. Kept on purpose: bare cells resolve empty at any slope (DX11 left steep ones auto, so a cliff flattened later regrew).
